# Car Auction — Telegram-бот + Mini App

Аукцион контейнеров с машинами. Каждый раунд разыгрывается контейнер: игроки
повышают ставку, после каждой ставки таймер запускается заново, последняя ставка
забирает контейнер. Внутри — случайная машина одной из четырёх редкостей.
Дальше гараж, продажа машин (государству или другому игроку), переводы, VIP,
расширение гаража, ежедневный бонус, рефералы, промокоды, магазин и админ-панель.

**Бот и Mini App — одна игра.** Состояние хранится в одной базе: ставка в Mini App
сразу появляется в сообщении комнаты в Telegram, ставка кнопкой в боте — в Mini App.

Работает на бесплатной serverless-платформе Telegram (**tgcloud**): без своего сервера,
PostgreSQL и Redis. Прежняя версия на Python (aiogram + PostgreSQL + Redis) лежит в
`legacy-python/`.

## Как устроено

| Где | Что |
|---|---|
| `tgcloud/lib/ddl.js`, `sql.js` | Схема базы и триггеры. Каждая денежная операция — одна команда SQL, все списания, начисления и журнал делают триггеры, поэтому операция либо проходит целиком, либо не проходит вовсе. Баланс не уходит в минус (CHECK). |
| `tgcloud/lib/engine.js` | Движок: комнаты, ставки, завершение контейнеров, розыгрыш машины, гараж, экономика, проверка целостности (`audit`). |
| `tgcloud/lib/live.js` | Синхронизация: «живые» сообщения комнат в чатах и уведомления (победа, кик, предложения, переводы). |
| `tgcloud/lib/views.js` | Общие представления для бота и Mini App. |
| `tgcloud/handlers/` | Бот: меню, `/play`, `/bet`, гараж, профиль, магазин; группы (`/play`, `/stop`). |
| `tgcloud/endpoints/` | Серверная часть Mini App (`app_room`, `app_garage`, `app_me`, `app_shop`, `app_img`, `app_admin`) и `ops`. |
| `web/` | Mini App (React + Vite). |
| `test/` | Тесты движка и синхронизации (`npm test`). |

### Таймер без таймеров

На платформе нет фоновых задач и `setTimeout`. Поэтому время «догоняется» при каждом
обращении к боту или Mini App (`tick()`): истёкшие контейнеры завершаются, следующие
запускаются, устаревшие сообщения перерисовываются. Mini App во время торгов
опрашивает сервер раз в секунду — пока в комнате кто-то сидит в Mini App, всё идёт
точно по времени. Если все играют только кнопками в чате и после последней ставки
никто ничего не нажимает, итог появится при следующем действии любого игрока.

### Что улучшено по сравнению с Python-версией

- Mini App: живой аукцион с таймером, анимация выпадения машины, гараж с карточками и
  характеристиками, магазин, профиль, лидеры, история операций.
- Админка в Mini App: настройки, каталог машин и контейнеров с загрузкой фото, состав и
  шансы контейнеров, игроки (баланс, VIP, бан, выдача машин и контейнеров), промокоды,
  лоты магазина, отмена контейнера и остановка комнаты.
- В комнату можно войти и ставить сразу, без ожидания конца текущего контейнера.
- Быстрая продажа (10%) доступна 15 минут после получения машины, дальше — продажа
  государству (40%); у VIP комиссии ниже.
- Продажа машины игроку: предложение приходит покупателю в бот, принятие — одной
  операцией (деньги и машина меняются местами атомарно).
- Стартовый каталог: 4 контейнера (Япония, Германия, США, Италия) × 8 машин.

### Картинки и права

Марки и модели — **вымышленные** (Kaito, Hoshi, Ryujin, Kessler, Rhein, Adler, Stallion,
Eagle, Liberty, Toro, Veloce, Lupo): реальные названия автопроизводителей — товарные
знаки, без лицензии использовать их в игре рискованно. Рисунки машин и морских
контейнеров — собственные (`web/src/art.js`, SVG): Mini App рисует их на лету, а для бота
они заранее рендерятся в JPEG (`npm run art` → `web/public/art/`) и отправляются по ссылке.
Фото, загруженное в админке, заменяет рисунок. Свои фото загружай только те, на которые
есть права (свои снимки или сгенерированные картинки с разрешением на использование).

## Команды

```bash
npm test                       # тесты
npm run build:web              # сборка Mini App
npx tgcloud push               # выкладка
npx tgcloud run endpoints/ops '{ action: "migrate" }' --ctx '{ initData: { user: { id: 777000 } } }'
npx tgcloud run endpoints/ops '{ action: "audit" }'   --ctx '{ initData: { user: { id: 777000 } } }'
npx tgcloud run endpoints/ops '{ action: "setup_bot" }' --ctx '{ initData: { user: { id: 777000 } } }'
```

Бот и адрес Mini App задаются в `tgcloud/lib/config.js`.
